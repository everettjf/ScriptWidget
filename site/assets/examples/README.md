# Homepage examples

These PNGs are unedited native Mac renders of the built-in `Habit Heatmap`,
`Countdown`, and `Reading Goal` templates, using the published ScriptWidget CLI
0.2.0 with light appearance and scale 2. They are not system widget screenshots.

- Heatmap: medium family, offline storage fixtures in `heatmap-fixtures.json`.
- Countdown: small family, parameter `2027-04-01 Spring break`.
- Reading Goal: small family, default example parameter `7,12`.

The CLI fixes its preview clock. Heatmap records are demonstration inputs only;
no template source or user storage was changed. The page labels these as example
data. Render again with `scriptwidget render <template-directory> --output <dir>
--family <family> --appearance light --scale 2` and the applicable `--fixtures`
or `--param` option.
