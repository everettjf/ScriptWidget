# Layout Starter

Copy this template into a project and open **Layout** above the code editor. Select a layer in the tree or select its JSX in Code. Edit text or choose a property and Apply. Drag a layer before another layer, use Move up/down, or select a container and Move inside. The stack/grid must contain literal JSX children; dynamic expressions remain in Code. Add text, stack, spacer and icon are available on supported containers.

Changes update the normal source file and preview. Undo and Redo share the editor history. The exported package includes your JSX, rather than an extra visual layout file. No-op opening/export preserves source text exactly. The template declares the five system widget families; accessory layouts require a separately designed compact composition.

All values here are literal and editable. Introduce variables or dynamic expressions in Code whenever you need them. Layout preserves those expressions and displays its editing boundary. It does not evaluate JavaScript, request system permission or replace unsupported source.

Open **Theme** and choose **Connect layout to Meadow theme** to bind literal styles to reusable tokens. Apply a palette, adjust individual fonts/spacing/colors, or copy/import version 1 theme JSON. Open **Assets** to select a literal container and insert original Bloom/Leaf marks or a static Pebble friend. Original art follows a connected theme and retains its MIT source/license in exported JSX. To add a photo, use the existing image import tools, then select a supported image from the package's `image/` directory in Assets. These commands share the normal save/preview and Undo history. The separate Pocket Pet template supplies persistent care interactions.
