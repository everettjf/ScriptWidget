# Photo Album Rotator

1. Install the whole package and open Settings → Photos in ScriptWidget.
2. Grant full or limited system photo access, select photos or albums, and save.
3. Open the installed widget in the app to prepare a private thumbnail snapshot.

Four thumbnails rotate across six-hour scheduled entries. System refresh timing may vary. Queries consider at most 64 source photos, expose four thumbnails, and retain snapshots for at most 24 hours. Hidden assets are excluded. Cloud-only photos must be downloaded in Photos first. Deleted assets, album changes and access changes invalidate snapshots before delivery. Limited access can hide albums; individual selected photos remain supported.

Browser previews use an original geometric landscape sample, not a real personal photo. Native execution never seeds photos. Manual Photo Card import remains available separately.

See [Photos API](../../../../../../../docs/photos-api.md).
