# Photo Card

Install this template, then open **Records & Configuration** from its menu. Choose a photo from Photos or import an image file. Adjust the crop's zoom and horizontal/vertical position, add the photo, select and reorder your pictures, choose Single/Two/Four-photo layout, then **Save Configuration**. Each installation keeps its own settings. Nothing is imported or saved merely by rendering the template.

Only the selected Photos item is transferred. The template itself cannot browse your photo library, read album identifiers, access the network, or modify the originals. Imported files are read with a 25 MiB bound, thumbnails normalize image orientation, and cropped package assets are at most 768 × 768 pixels. Original GPS and capture-time metadata are discarded; image dimensions and color-space information may be generated by the PNG encoder. Animated inputs use their first frame. Download unavailable iCloud originals before importing.

Keep up to 12 imported assets and select up to four. The configuration screen lets you remove an unused imported photo after confirmation. It does not delete assets referenced by either the saved configuration or your current selection. Missing selected files are identified in the configuration screen so you can reconnect storage or choose replacements.

The small and circular accessories show the first selected image; medium displays the selected layout in one row; large widgets show the collage in rows. Inline accessories show the title. The default widget shows an empty-state guide until you choose photos. A gallery thumbnail uses original code-drawn sample artwork, not personal photos.

The optional per-widget JSON parameter may override `title`, `caption`, `layout` (`single`, `duo` or `grid`) and `photos`. A photo name is the package-local `photo-<UUID>` shown in its settings backup; no URLs, arbitrary paths or cross-package assets are accepted. Titles support 40 UTF-16 code units and captions 80. Native configuration is the recommended way to select photos.

**Backups:** a record backup contains settings and photo references only. Export the complete widget package to include image files. Keep both if you want to restore the layout and pictures on another device. Restoring settings alone can leave missing images; it does not silently insert demo pictures. Records are local to the installation and do not synchronize through iCloud, even when source files are in iCloud Drive.
