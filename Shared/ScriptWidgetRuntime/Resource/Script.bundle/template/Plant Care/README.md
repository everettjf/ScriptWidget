# Plant Care

Install this complete package, then open **Records & Configuration** to set the name, review history and export/restore records. Use the widget’s explicit care buttons; refreshing never fabricates care.

Original JSX artwork works offline in light/dark appearances and all supported sizes. Static shapes do not require animation. Records are retained for up to 366 local calendar days, with Undo for the last edit.

See [local plants and pets](../../../../../../../docs/local-companions.md) for behavior, schedules, system actions and data limits.
