ScriptWidget lets users create native widgets with JavaScript and JSX. This update adds persistent local record templates and improves template configuration, offline caching and preview tools. No login is required for built-in local templates. Real Calendar, Location and iOS Health templates require explicit system access in the app; uninstalled previews never query personal data. Web Studio uses editable sample data. Review can start with Habit Heatmap, Hydration Goal or Countdown. Calendar, Reminders, Photos and Health features use explicit user-selected sources and system access where supported. Reminders writes require an explicit declared user action and write permission. GitHub connection is optional and requires approval per widget. iOS Music exposes a read-only snapshot; playback control and Spotify are not included. The App/Share extension supports iOS 16+, the Widget extension requires iOS 18+, and the macOS app and widget require macOS 26+.
