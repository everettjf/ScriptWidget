ScriptWidget lets users create native widgets with JavaScript and JSX. This update adds persistent local record templates and improves template configuration, offline caching and preview tools. No login is required for built-in local templates. Review can start with Habit Heatmap, Hydration Goal or Countdown. Calendar, Reminders and Photos require explicit system access and user-selected sources. Reminders writes require an explicit declared user action and write permission. GitHub connection is optional and requires approval per widget. Web Studio uses editable sample data. Health and Music device data are not available in the macOS app. Spotify is not included. The macOS app and widget require macOS 26+.
