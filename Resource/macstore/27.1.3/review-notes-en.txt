ScriptWidget lets users create native widgets with JavaScript and JSX. This update adds persistent local record templates and improves template configuration, offline caching and preview tools. No login is required for built-in local templates. Real Calendar, Location and iOS Health templates require explicit system access in the app; uninstalled previews never query personal data. Web Studio uses editable sample data. Review can start with Habit Heatmap, Hydration Goal or Countdown. Reminders and authenticated music/account features are not included in this build.
